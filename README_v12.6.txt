JP Manga Translator v12.6

以 v12.5 为底，OCR / Hy-MT2 / Manga LaMa 核心未改。

本版重点：
1. OCR 后先进入人工框选：每页可拖动、缩放、删除、新增、合并框，并可直接改 OCR 文字。
2. 你确认/锁定后才翻译。
3. 手动确定的框，后面绝不再自动拆分或合并。
4. 气泡继续原来的气泡排版；拉成大框或标成「长对白」后，内部用横排中文。
5. 中文字号再加大（FONT_SCALE=1.62），描边与对比明显加强。
6. 初次识别会把明显是同一句话的碎框合成一个框；隔开的两个气泡仍然分开。
7. 批量处理界面和进度显示保持 v12.5：总页数、已完成、失败、当前文件名、当前阶段、右侧预览。

使用：
1. 运行 install_windows_v12_6.bat（第一次用或依赖缺失时）。
2. 确认 Ollama 中已有 hy-mt2-7b。
3. 确认 models/PP-OCRv6_manga 和 models/AnimeMangaInpainting 已经存在。
4. 运行 start_windows_v12_6.bat，打开 http://127.0.0.1:7860
5. 第一步选择图片或 ZIP/CBZ/7Z/RAR，运行 OCR，在红框上改到满意后锁定。
6. 第二步点击「一键开始批量翻译并生成 ZIP」。

快捷键：V 选择，N 画框，M 两步合并，Delete 删除，Ctrl+Z 撤回，Ctrl+Y 重做。
右键按住拖动画面（不移动图片）；滚轮以光标为中心缩放。放大后红框坐标与画面一致，不用刷新也能点到。
合并：先点第一个框，再点「合并」，再点第二个框。也可按住 Shift 选两个框后按 M。
中文优先系统雅黑/黑体，其次使用 fonts/NotoSansSC.ttf，避免翻译字变成口口。
